# **WEEK 1 - Requirements, Research, and Environment Setup**

### **What We Did This Week:**

1. **Broke the project into milestones and reviewed the spec**

   * Milestone parts: (1) database schema + migrations, (2) auth + manual-entry CRUD, (3) OCR pipeline, (4) analytics + insights, (5) targets + alerts.
   * Reviewed the product spec: OCR fields (amount, date, item, payment method, merchant, currency), onboarding survey (display name, category, priorities), dashboards, monthly comparisons, recurring payments, spending targets.
2. **Researched and chose the tech stack for Backend**

   * FastAPI (async, auto Swagger docs, built-in Pydantic validation).
   * PostgreSQL for exact Numeric money handling, JSONB, and future analytics.
   * SQLAlchemy 2.0 with the new Mapped/mapped\_column typed style.
   * Alembic for versioned migrations.
3. **Set up the project and environment**

   * Created the project skeleton and the Python 3.13 virtual environment.
   * Installed fastapi, uvicorn, sqlalchemy, psycopg2-binary, alembic, asyncpg, python-dotenv.
   * Got a Hello-World FastAPI app running.
   * Left `sqlalchemy.url` blank in `alembic.ini` so the real connection string lives only in `.env`, never committed to git.
   * Added `.gitignore` entries for `.env`, `.venv`, `\_\_pycache\_\_`.
4. **Fixed the database connection problems**

   * **Problem 1:** Assumed the default Postgres password and wrote `DATABASE\_URL=postgresql://postgres:postgres@localhost:5432/expense\_tracker`. Connecting failed with `psycopg2.OperationalError: ... FATAL: password authentication failed for user "postgres"`. The server was up (port 5432 listening), so it was purely a credential issue. Had to ask for the real credentials instead of guessing.
   * **Problem 2:** Alembic wouldn't initialize with asyncpg and ran synchronously. Solved by adding psycopg2-binary for the migration tooling while keeping asyncpg available for the app.
   * **Problem 3:** The app loaded `.env` but `alembic/env.py` ignored it. Fix: call `load\_dotenv()` inside `env.py` and set the URL with `config.set\_main\_option("sqlalchemy.url", os.environ\["DATABASE\_URL"])`.
